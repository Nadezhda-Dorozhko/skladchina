# Лабораторная №6. Сервер «Складчины» на Express + Mongoose (MongoDB)

1. `npm install`
2. Скопировать `.env.example` в `.env` и вписать строку подключения MongoDB (`MONGO_URI`) и `JWT_SECRET`.
3. `npm run seed` – тестовые данные (admin@skladchina.local / Admin123!, user@skladchina.local / User123!).
4. `npm run dev` – сервер на http://localhost:3000.
5. Postman: импортировать `skladchina-mongo.postman_collection.json`.
