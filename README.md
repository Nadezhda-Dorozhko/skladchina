# Складчина — практическое занятие №1 (ветка pz21)

Express-приложение с шаблонизатором EJS: главная, детальная страница, форма добавления,
страницы ошибок 404 и 500. Складчины хранятся в массиве в памяти, журнал запросов
записывается в консоль и `logs/app.txt`.

## Запуск

```bash
npm install
npm start
```

## Страницы

| Метод | URL         | Описание                             |
| ----- | ----------- | ------------------------------------ |
| GET   | `/`         | Список складчин                      |
| GET   | `/item/:id` | Детальная страница                   |
| GET   | `/add`      | Форма добавления                     |
| POST  | `/add`      | Добавление в массив, редирект на `/` |
| GET   | `/login`    | Форма имитации входа                 |
| POST  | `/logout`   | Выход из аккаунта                    |

Вход имитируется: точный query-параметр `auth=1` устанавливает cookie `mc_auth`.
Только авторизованный пользователь может открыть `/add` и отправить форму. POST
запрос формы проходит ограничение частоты, проверку Content-Type и очистку строк.
Складчины и журнал запросов не требуют базы данных. Максимальная длина URL в журнале
настраивается в `config/limits.json`. Ошибка записи журнала не прерывает обработку
запроса. REST API `/purchases` из лабораторной работы №1 сохранён.
