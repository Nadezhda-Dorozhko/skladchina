# Складчина — практическое занятие №1 (ветка pz21)

Express-приложение с шаблонизатором EJS: главная, детальная страница, форма добавления,
страницы ошибок 404 и 500. Складчины хранятся в массиве в памяти, журнал запросов — в таблице
`request_logs` базы PostgreSQL.

## Запуск

```bash
npm install
# база данных должна существовать (по умолчанию skladchina)
createdb skladchina
npm start
```

Параметры подключения: `DB_HOST`, `DB_PORT`, `DB_USER`, `DB_PASSWORD`, `DB_NAME`
(по умолчанию localhost:5432, postgres/postgres, skladchina). Если база недоступна,
сервер не запускается и выводит сообщение об ошибке.

## Страницы

| Метод | URL | Описание |
|-------|-----|----------|
| GET | `/` | Список складчин |
| GET | `/item/:id` | Детальная страница |
| GET | `/add` | Форма добавления |
| POST | `/add` | Добавление в массив, редирект на `/` |
| GET | `/error` | Демонстрация страницы 500 |

`?auth=1` — имитация авторизации (пользователь «Организатор»), иначе «Гость».
Ограничения значений формы — в `config/limits.json`. REST API `/purchases` из лабораторной работы №1 сохранён.
